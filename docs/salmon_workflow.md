
# Salmon: Transcript Quantification

## 1. Software and Environment

Salmon was used for transcript-level quantification of RNA-seq data.

- Software: Salmon
- Version: 1.10.3
- Operating system: Ubuntu (WSL)
- Reference transcriptome: GENCODE v37
- Sequencing strategy: Paired-end
- Threads used: 4

### Installation

```bash
sudo apt install salmon
```

### Version verification

```bash
salmon --version
```

## 2. Reference Transcriptome

The reference transcriptome used was:

`gencode.v37.transcripts.fa.gz`

Location:

`Reference/gencode.v37.transcripts.fa.gz`

## 3. Index Construction

The Salmon index was constructed using the GENCODE v37 transcriptome.

```bash
salmon index \
  -t Reference/gencode.v37.transcripts.fa.gz \
  -i Reference/salmon_index_v1.10.3_k25 \
  --gencode \
  -k 25 \
  -p 4
```

### Parameters

- `-t`: transcriptome reference file.
- `-i`: output directory for the index.
- `--gencode`: indicates GENCODE-formatted transcript identifiers.
- `-k 25`: k-mer length of 25.
- `-p 4`: four processing threads.

## 4. Transcript Quantification

Quantification was performed using paired-end sequencing reads (R1 and R2).

The library type was automatically detected using `-l A`.

The mapping validation option `--validateMappings` was included.

### 4.1 Individual quantification: S1

The first sample was quantified individually.

```bash
salmon quant \
  -i Reference/salmon_index_v1.10.3_k25 \
  -l A \
  -1 Datos/Archivo_fast/s1_R1.fastq.gz \
  -2 Datos/Archivo_fast/s1_R2.fastq.gz \
  --validateMappings \
  -p 4 \
  -o Output/salmon_quant/s1_quant
```

### 4.2 Automated quantification: S2-S12

The remaining eleven samples were processed using a Bash `for` loop.

```bash
for n in {2..12}; do
    echo "Cuantificando muestra s${n}"

    salmon quant \
      -i Reference/salmon_index_v1.10.3_k25 \
      -l A \
      -1 "Datos/Archivo_fast/s${n}_R1.fastq.gz" \
      -2 "Datos/Archivo_fast/s${n}_R2.fastq.gz" \
      --validateMappings \
      -p 4 \
      -o "Output/salmon_quant/s${n}_quant" || break
done
```

This loop automated the quantification of samples S2 through S12.

S1 was processed separately before executing the loop.

## 5. Output Files

Each sample generated a quantification directory containing:

- `quant.sf`: transcript-level quantification estimates.
- `aux_info/`: additional information generated by Salmon.
- `aux_info/meta_info.json`: mapping and quantification statistics.

Results were stored in:

`Output/salmon_quant/`

The directory structure was:

```text
salmon_quant/
├── s1_quant/
├── s2_quant/
├── s3_quant/
├── ...
└── s12_quant/
```

## 6. Inspection of Quantification Results

### Inspect transcript quantification

The first six lines of the S1 quantification file were inspected using:

```bash
head -n 6 Output/salmon_quant/s1_quant/quant.sf
```

### Inspect mapping statistics

The following command was used to retrieve the principal mapping statistics from the metadata file:

```bash
grep -E '"(num_processed|num_mapped|percent_mapped)"' \
  Output/salmon_quant/s1_quant/aux_info/meta_info.json
```

## 7. Workflow Summary

The Salmon workflow consisted of:

1. Installation and version verification.
2. Reference transcriptome preparation.
3. Index construction.
4. Individual quantification of S1.
5. Automated quantification of S2-S12.
6. Inspection of quantification estimates and mapping statistics.

A total of 12 paired-end samples were quantified.
